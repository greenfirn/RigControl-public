ENCRYPTED MQTT (TLS) - BASIC - dashboard server (docker mosquitto), agents and server

TLS on port 8883 is the default. two stages:
  A. test mode (MQTT_TLS_INSECURE): encrypted, the broker certificate is not checked. only the server certificate (step 1) is needed,
     nothing is copied to the workers. this is what the install scripts and .env.example do out of the box.
  B. verified TLS: copy ca.crt to the workers and turn the insecure option off (step 6).
Replace 10.10.0.10 below with the ip agents use to reach the broker.

install openssl if missing (skip if 'openssl version' works):

openssl version || (sudo apt update && sudo apt install -y openssl)

1. create the certificates in ~/ha-docker/mosquitto/config/certs
   (san.ext lists every address a client may use: the broker ip, 127.0.0.1 for the server on the same pi, and a hostname if you use one: add ,DNS:yourhost)

sudo mkdir -p ~/ha-docker/mosquitto/config/certs && cd ~/ha-docker/mosquitto/config/certs
sudo openssl genrsa -out ca.key 4096
sudo openssl req -x509 -new -nodes -key ca.key -sha256 -days 3650 -subj "/CN=RigControl MQTT CA" -out ca.crt
sudo openssl genrsa -out server.key 2048
sudo openssl req -new -key server.key -subj "/CN=10.10.0.10" -out server.csr
printf "subjectAltName=IP:10.10.0.10,IP:127.0.0.1" | sudo tee san.ext > /dev/null
sudo openssl x509 -req -in server.csr -CA ca.crt -CAkey ca.key -CAcreateserial -out server.crt -days 825 -sha256 -extfile san.ext
sudo chown 1883:1883 server.key server.crt ca.crt
sudo chmod 640 server.key

   keep ca.key private. only ca.crt is copied to workers.

2. broker config: mosquitto/config/mosquitto.conf already has the TLS listener (8883, certs from the folder above).
   create the mosquitto password file if you have not already, then start/restart:

cd ~/ha-docker && sudo docker compose up -d mosquitto

3. test the broker (2 checks)

openssl s_client -connect 10.10.0.10:8883 </dev/null | head -5
   expect the certificate (CN = 10.10.0.10, issuer RigControl MQTT CA) and 'verify error:num=19:self-signed certificate in certificate chain' (no CA given)

openssl s_client -connect 10.10.0.10:8883 -CAfile ~/ha-docker/mosquitto/config/certs/ca.crt </dev/null | grep -i "verify return\|Verify return code"
   expect 'verify return:1' and 'Verify return code: 0 (ok)'

4. dashboard server (.env): MQTT_HOST must be an address in san.ext (10.10.0.10 or 127.0.0.1). the defaults already are:

MQTT_PORT=8883
MQTT_TLS=true
MQTT_TLS_INSECURE=true

   docker-compose.yml already mounts ./mosquitto/config/certs at /mqtt-certs

5. each worker (stage A, nothing to copy): the agent install scripts (rigcontrol-agent-local.sh / copy-paste-update.sh) already write BROKER_PORT=8883,
   MQTT_TLS=1 and MQTT_TLS_INSECURE=1. just set BROKER_HOST / BROKER_USER / BROKER_PASS in the script, regenerate copy-paste-update.sh and run it on the worker
   as a file (scp + bash, do not paste it into the terminal). windows worker: same keys in C:\rigcontrol\rigcontrol_agent.conf.

6. verified TLS (stage B), when stage A works: copy the broker's ca.crt to /etc/rigcontrol/ca.crt on each worker once (the install scripts never overwrite it):

# run on the broker pi, once per worker (replace user@WORKER with the worker login)
scp ~/ha-docker/mosquitto/config/certs/ca.crt user@WORKER:/tmp/ca.crt
ssh -t user@WORKER "sudo mkdir -p /etc/rigcontrol && sudo mv /tmp/ca.crt /etc/rigcontrol/ca.crt"
# check: the worker prints the same certificate
ssh user@WORKER "openssl x509 -in /etc/rigcontrol/ca.crt -noout -subject -enddate"

   or pull it from the worker instead (run on the worker; pi login user@pi5-ubuntu):

scp user@pi5-ubuntu:~/ha-docker/mosquitto/config/certs/ca.crt /tmp/ca.crt
sudo mkdir -p /etc/rigcontrol && sudo mv /tmp/ca.crt /etc/rigcontrol/ca.crt
openssl x509 -in /etc/rigcontrol/ca.crt -noout -subject -enddate

   then comment out MQTT_TLS_INSECURE=1 and uncomment #MQTT_CA_FILE=/etc/rigcontrol/ca.crt in rigcontrol-agent-local.sh (windows conf: #MQTT_CA_FILE=C:\rigcontrol\ca.crt), regenerate copy-paste-update.sh and run it on the worker
   as a file. on the server set MQTT_TLS_INSECURE=false and uncomment MQTT_CA_FILE=/mqtt-certs/ca.crt in .env, then recreate the container.

   windows worker: same keys in C:\rigcontrol\rigcontrol_agent.conf, ca.crt at C:\rigcontrol\ca.crt

7. plain MQTT (no encryption) is still possible, see mosquitto-no-tls-setup.txt.
   MQTT_TLS_INSECURE=1 (workers) / MQTT_TLS_INSECURE=true (server) skips certificate and hostname checks: stage A only, not for production.

advanced (optional): client certificates / mutual TLS, see mosquitto-tls-advanced.txt
