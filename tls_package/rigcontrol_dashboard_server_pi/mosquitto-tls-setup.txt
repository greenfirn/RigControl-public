ENCRYPTED MQTT (TLS) - dashboard server (docker mosquitto), agents and server

install openssl if missing (skip if 'openssl version' works):

openssl version || (sudo apt update && sudo apt install -y openssl)

1. create the certificates in ~/ha-docker/mosquitto/config/certs
   broker ip: 10.10.0.10 (if agents use a hostname instead, add DNS:yourhost to san.ext)

sudo mkdir -p ~/ha-docker/mosquitto/config/certs && cd ~/ha-docker/mosquitto/config/certs
sudo openssl genrsa -out ca.key 4096
sudo openssl req -x509 -new -nodes -key ca.key -sha256 -days 3650 -subj "/CN=RigControl MQTT CA" -out ca.crt
sudo openssl genrsa -out server.key 2048
sudo openssl req -new -key server.key -subj "/CN=10.10.0.10" -out server.csr
printf "subjectAltName=IP:10.10.0.10" | sudo tee san.ext > /dev/null
sudo openssl x509 -req -in server.csr -CA ca.crt -CAkey ca.key -CAcreateserial -out server.crt -days 825 -sha256 -extfile san.ext
sudo chown 1883:1883 server.key server.crt ca.crt
sudo chmod 640 server.key

2. enable the TLS listener (keeps plain 1883 running)

cd ~/ha-docker/mosquitto/config/conf.d
sudo cp tls.conf.example tls.conf
cd ~/ha-docker && sudo docker compose restart mosquitto

3. dashboard server: set in .env, then rebuild/restart rigcontrol-ws

MQTT_TLS=true
MQTT_PORT=8883
MQTT_CA_FILE=/mqtt-certs/ca.crt

4. each worker: copy ca.crt to /etc/rigcontrol/ca.crt and set in /etc/rigcontrol/rigcontrol-agent.conf, then restart the agent

BROKER_HOST=10.10.0.10
BROKER_PORT=8883
MQTT_TLS=1
MQTT_CA_FILE=/etc/rigcontrol/ca.crt

   windows worker: same keys in the agent conf, MQTT_CA_FILE=C:\path\ca.crt

5. test

openssl s_client -connect 10.10.0.10:8883 -CAfile ca.crt </dev/null | grep -i "verify return"

   once everything connects on 8883 you can remove the plain 'listener 1883' from mosquitto.conf
   MQTT_TLS_INSECURE=1 skips certificate / hostname checks (testing only)
